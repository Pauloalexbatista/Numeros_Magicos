## 5. ⚙️ The Nature of a "System"

A System is a specific lens through which we analyze numbers. It can be mathematical, statistical, neural, or "spiritual/illogical".

### 📜 The Immutable Laws of Systems

1. **Consistency:** Once a rule is defined, it applies to the **entire history**. We do not cherry-pick.
2. **Backtesting:** We calculate predictions from the first possible draw to the last.
3. **Chain Logic:**
    * *Draw N* happens.
    * We compare *Draw N* results with *Prediction for N* (generated at N-1).
    * We generate *Prediction for N+1*.
4. **Efficiency:** New draws are processed **once**. We do NOT recalculate the entire history for every new draw (Incremental Update).

### 🏆 The Quality Score (Ranking Logic)

To determine the "Best" systems, we use a weighted point system that prioritizes high-value wins.
The classification changes dynamically based on the selected filter (Last 20, Last 50, All-Time).

| Hit Count | Points Awarded |
| :--- | :--- |
| **6 Hits** (Jackpot - EuroDreams) | **10,000 pts** |
| **5 Hits** (Jackpot - EuroMillions/Totoloto) | **1,000 pts** |
| **4 Hits** | **100 pts** |
| **3 Hits** | **1 pt** |
| **0-2 Hits** | **0 pts** |
